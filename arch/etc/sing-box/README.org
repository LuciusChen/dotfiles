#+TITLE: sing-box 配置更新
#+OPTIONS: toc:nil

* 架构

路由、DNS、节点合并和远程规则集由私有 Cloudflare Worker 维护。本机只保存最后
一份验证通过的配置，并由 systemd 每六小时检查更新。

- =/etc/sing-box/sing-box-update.sh=：下载、校验并原子替换配置
- =/etc/sing-box/profile-url=：私有 Linux profile URL（权限 0600，不进入 Git）
- =/etc/sing-box/config.json=：当前运行配置（由更新脚本生成）
- =sing-box-profile-update.timer=：开机后和每六小时触发更新

下载或校验失败不会改动当前配置。配置没有变化时不会重启 sing-box；新配置启动
失败时会从 =config.json.previous= 恢复。

* 常用命令

#+begin_src sh
sudo systemctl start sing-box-profile-update.service
sudo systemctl status sing-box-profile-update.service
systemctl list-timers sing-box-profile-update.timer
journalctl -u sing-box-profile-update.service
journalctl -u sing-box.service
#+end_src

主配置在 Worker 仓库中维护，不再在本目录维护模板或本地规则集下载逻辑。
